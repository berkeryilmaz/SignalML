⚡ Model Mimarisi Sihirbazı (Architecture Wizard)

Autoencoder, 1D U-Net, CNN, LSTM veya Transformer mimarilerini tek tıkla otomatik oluşturun ve bağlayın.

1. Model Mimarisi Seçin:
1D Convolutional Autoencoder Denoising / AE

Encoder (Conv1D + MaxPool) → Bottleneck Latent → Decoder (UpSampling1D + Conv1D) → Sinyal Yeniden Yapılandırma Çıktısı.

1D U-Net (Skip Connections) U-Net / Seg

Encoder seviyelerinden Decoder'a Concatenate skip bağlantıları. Tepe noktalarını ve yüksek frekans detaylarını korur.

Dense / MLP Autoencoder Boyut İndirgeme

Flatten → Dense Encoder → Latent Code → Dense Decoder → Reshape. Sinyal sıkıştırma ve anomali tespiti için.

1D CNN Sinyal Sınıflandırıcı Sınıflandırma

Conv1D + MaxPool öznitelik çıkarımı → Global Pooling → Dense Softmax çıkışı.

Bidirectional LSTM Zaman Serisi

Çift yönlü LSTM katmanı + Tek yönlü LSTM + Dense. Uzun vadeli bağımlılıkları ve periyodik sinyalleri yakalar.

1D Transformer (Self-Attention) Attention

Projeksiyon → Positional Encoding → MultiHeadAttention → Residual Add → LayerNorm.

1D-CNN IDEC (Clustering + AE) IDEC / 1D-CNN

1D-CNN Encoder → Bottleneck → Çift Çıkış: ClusteringLayer (KLD Kümeleme) + 1D-CNN Decoder (MSE Rekonstrüksiyon).

Dense / MLP IDEC IDEC / Dense

Dense Encoder → Bottleneck → Çift Çıkış: ClusteringLayer (KLD) + Dense Decoder (MSE).

Hibrit 1D-CNN + Tabular Model Multi-Input / Füzyon

Çok Girişli Mimari: Sinyal Dalga Formu (1D-CNN) + Tabular Metaveri (Dense) → Concatenate → Sınıflandırma Başı.
