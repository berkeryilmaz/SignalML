Generate and wire Autoencoder, 1D U-Net, CNN, LSTM, or Transformer architectures in one click.

1D Convolutional Autoencoder Denoising / AE

Encoder (Conv1D + MaxPool) → Bottleneck Latent → Decoder (UpSampling1D + Conv1D) → Signal Reconstruction Output.

1D U-Net (Skip Connections) U-Net / Seg

Concatenate skip connections from Encoder levels to Decoder. Preserves sharp peaks and high-frequency details.

Dense / MLP Autoencoder Dim Reduction

Flatten → Dense Encoder → Latent Code → Dense Decoder → Reshape. For signal compression and anomaly detection.

1D CNN Signal Classifier Classification

Conv1D + MaxPool feature extraction → Global Pooling → Dense Softmax output.

Bidirectional LSTM Time Series

Bidirectional LSTM layer + Unidirectional LSTM + Dense. Captures long-term dependencies and periodic signals.

1D Transformer (Self-Attention) Attention

Projection → Positional Encoding → MultiHeadAttention → Residual Add → LayerNorm.

1D-CNN IDEC (Clustering + AE) IDEC / 1D-CNN

1D-CNN Encoder → Bottleneck → Dual Output: ClusteringLayer (KLD Clustering) + 1D-CNN Decoder (MSE Reconstruction).

Dense / MLP IDEC IDEC / Dense

Dense Encoder → Bottleneck → Dual Output: ClusteringLayer (KLD) + Dense Decoder (MSE).

Hybrid 1D-CNN + Tabular Model Multi-Input / Fusion

Multi-input architecture: Signal Waveform (1D-CNN) + Tabular Metadata (Dense) → Concatenate → Classification Head.
